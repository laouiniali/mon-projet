🚀 Guide GitHub

Pour pousser votre projet Angular sur GitHub

✅ Bonne nouvelle! Git est déjà initialisé dans votre projet!

📝 Étape 1: Créer le dépôt sur GitHub

AVANT TOUT, créez le dépôt sur GitHub:

  1. Allez sur https://github.com/new
  2. Repository name: mon-projet
  3. Description: Angular Conference Management App - ESPRIT
  4. Visibilité: ☑️ Cochez Public
  5. Ne cochez RIEN d'autre (pas de README, pas de .gitignore)
  6. Cliquez sur "Create repository"
📱 Créer le dépôt maintenant

💻 Étape 2: Ouvrir PowerShell

  1. Appuyez sur Windows + X
  2. Choisissez "Windows PowerShell" ou "Terminal"
  3. Tapez cette commande pour aller dans le dossier:
cd c:\mon-projet

⚙️ Étape 3: Configurer Git

Copiez et exécutez ces commandes UNE PAR UNE:

1. Configurer votre nom:

git config user.name "Ali Laouini"

2. Configurer votre email:

git config user.email "ali.laouini@esprit.tn"

3. Ajouter les fichiers:

git add .

4. Créer le commit:

git commit -m "Initial commit: Angular Conference App with CRUD"

5. Ajouter GitHub:

git remote add origin https://github.com/laouiniali/mon-projet.git

6. Renommer la branche:

git branch -M main

🔐 Étape 4: Créer un Token GitHub

⚠️ IMPORTANT: N'utilisez PAS votre mot de passe GitHub! Utilisez un TOKEN.
  1. Allez sur https://github.com/settings/tokens
  2. Cliquez sur "Generate new token (classic)"
  3. Note: "Mon Projet Angular ESPRIT"
  4. Expiration: 90 days
  5. Cochez: ☑️ repo (toutes les sous-cases)
  6. Cliquez sur "Generate token"
  7. ⚠️ COPIEZ LE TOKEN IMMÉDIATEMENT! (vous ne le reverrez jamais)
🔑 Créer un token

🚀 Étape 5: Pousser sur GitHub

Maintenant, poussez le code:

git push -u origin main

Quand on vous demande:

  • Username: laouiniali
  • Password: COLLEZ_VOTRE_TOKEN_ICI (pas votre mot de passe!)
