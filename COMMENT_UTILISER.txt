🚀 MÉTHODE RAPIDE (3 ÉTAPES):

1️⃣  Double-cliquez sur: init-git.bat
    → Cela va initialiser Git et créer le premier commit

2️⃣  Ouvrez PowerShell dans ce dossier et tapez:
    git push -u origin main

3️⃣  Entrez vos identifiants quand demandé:
    Username: ali.laouini@esprit.tn
    Password: Votre mot de passe GitHub


⚠️  IMPORTANT - SÉCURITÉ:
    
    Pour éviter les problèmes, utilisez un TOKEN au lieu du mot de passe:
    
    1. Allez sur: https://github.com/settings/tokens
    2. Cliquez "Generate new token (classic)"
    3. Donnez un nom: "Mon Projet Angular ESPRIT"
    4. Cochez: "repo" (toutes les cases)
    5. Cliquez "Generate token"
    6. COPIEZ LE TOKEN (vous ne le reverrez plus!)
    7. Utilisez ce token comme "mot de passe" lors du push


📱 MÉTHODE ENCORE PLUS SIMPLE (GitHub Desktop):

    1. Téléchargez: https://desktop.github.com/
    2. Installez et connectez-vous
    3. File > Add Local Repository > Sélectionnez c:\mon-projet
    4. Cliquez "Publish repository"
    5. Cochez "Public" pour le rendre accessible à tous
    6. Terminé! 🎉


🌐 RENDRE LE DÉPÔT PUBLIC:

    Après le push, allez sur:
    https://github.com/laouiniali/mon-projet
    
    Settings > Danger Zone > Change visibility > Make public


📞 BESOIN D'AIDE?

    Si vous avez des problèmes:
    1. Lisez INSTRUCTIONS_GIT.md pour plus de détails
    2. Vérifiez que Git est installé: git --version
    3. Vérifiez votre connexion GitHub
